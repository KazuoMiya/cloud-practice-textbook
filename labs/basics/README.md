# 第6章と付録Fの確認用スクリプト

「クラウド実践テキスト」第6章の「手元で確かめる」と、付録F（LinuxとGitの基礎）に載せたコマンドを、本に載せた順に実行し、結果を確かめるスクリプトです。

| ファイル | 中身 |
|---|---|
| `verify.sh` | Amazon Linux 2023 のコンテナを起動し、その中で `inside.sh` を実行する |
| `inside.sh` | 本文のコマンドを、本文のとおりに書いて実行し、出力や終了コードを確かめる |

```bash
bash labs/basics/verify.sh
```

このリポジトリのCIでは、本文を変えるたびに、次のことを確かめています。

- 本文の該当の節にあるコマンドが、すべて `inside.sh` の中に、本文と同じ順で書かれている（`tests/test_basics_lab.py`）
- そのコマンドが、Amazon Linux 2023 のコンテナで最後まで動き、本文で説明したとおりの結果になる（成功するはずのものは成功し、失敗するはずのものは、説明した理由と終了コードで失敗する）

systemd を使うコマンド（`systemctl`、`journalctl`）は、コンテナでは動かないため、ここでは実行していません。第14章のサーバーで試します。

学ぶ人は、このスクリプトを使う必要はありません。本文のコマンドを、CloudShell かコンテナで、1行ずつ打ち込んで試してください。
